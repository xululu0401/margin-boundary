# 保本边界台
本地运行的月经营盈亏与产能边界计算器。打开index.html即可；node build.cjs合并源码，node --test tests/core.test.cjs运行验证。无构建依赖；封面渲染另用sharp（脚本中的本机路径需按环境修改）。

输入价格、变动成本、扣点、固定开支、营业天数、日订单、日上限、月利润目标。输出整数保本/目标量、当前利润、容量约束、目标单价、九格情景以及PNG/Markdown/CSV/JSON。

算法见页面“算法与边界”。金额及扣点转换为整数，BigInt判断临界整单和分位价格。输出金额四舍五入仅用于显示，阈值计算保留精度。界面均为自填假设，不预测需求、不提供投资回报承诺。
